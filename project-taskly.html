Taskly — Task Management App

Aplikasi manajemen tugas berbasis web yang dirancang untuk membantu pengguna mengatur aktivitas sehari-hari melalui tampilan Kanban Board. Dilengkapi dengan pengelolaan tugas, prioritas, tenggat waktu, autentikasi pengguna, dan penyimpanan data secara online.

Dashboard — Task Overview

Fungsi Website

Taskly dikembangkan sebagai aplikasi untuk membantu pengguna mengelola dan memantau tugas dalam satu dashboard. Pengguna dapat mengatur status pekerjaan, menentukan prioritas, menetapkan tenggat waktu, serta melihat perkembangan tugas melalui tampilan Kanban Board yang responsif.

Fitur-fitur yang Dibuat

  • User Authentication — registrasi dan login menggunakan akun pengguna
  • Kanban Board — pengelompokan tugas berdasarkan status To Do, In Progress, dan Done
  • Task Management — menambah, mengubah, dan menghapus tugas
  • Task Priority — pengaturan tingkat prioritas tugas
  • Due Date — penentuan dan pemantauan tenggat waktu
  • Overdue Indicator — penanda visual untuk tugas yang melewati tenggat waktu dan belum selesai
  • Cloud Data Storage — penyimpanan data tugas secara online
  • Responsive Design — tampilan yang menyesuaikan perangkat
  • Dark Mode — pilihan tampilan terang dan gelap

Keterangan

Proyek ini dikembangkan secara mandiri dengan Next.js dan TypeScript menggunakan pendekatan komponen untuk membangun antarmuka yang terstruktur. Zustand digunakan untuk pengelolaan state aplikasi, sedangkan Supabase dimanfaatkan untuk autentikasi dan penyimpanan data. Aplikasi kemudian dideploy menggunakan Vercel.
