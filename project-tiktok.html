Tugas Akhir · Hybrid IndoBERT + XGBoost

Prediksi Popularitas Konten Mental Health TikTok

Model machine learning hybrid untuk mengklasifikasikan tingkat popularitas konten bertema kesehatan mental di TikTok Indonesia, dikembangkan sebagai tugas akhir (skripsi) dengan pendekatan gabungan representasi bahasa (IndoBERT) dan model boosting (XGBoost).

Dashboard Hasil Evaluasi Model

Fungsi Proyek

Proyek ini bertujuan membangun model yang mampu memprediksi seberapa populer sebuah konten TikTok bertema kesehatan mental, berdasarkan fitur teks (caption, komentar) dan metadata konten — membantu memahami pola konten yang paling banyak menjangkau audiens di topik sensitif seperti kesehatan mental.

Fitur & Tahapan yang Dikerjakan

  • Pengumpulan dan pembersihan data konten TikTok berbahasa Indonesia
  • Preprocessing teks (tokenisasi, normalisasi, penghapusan noise)
  • Penyeimbangan data dengan teknik SMOTENC untuk mengatasi data tidak seimbang
  • Ekstraksi representasi teks menggunakan IndoBERT
  • Feature engineering menggabungkan representasi IndoBERT dengan fitur metadata
  • Klasifikasi popularitas konten menggunakan XGBoost
  • Evaluasi model dengan metrik akurasi, precision, recall, dan F1-score

Hasil

Model hybrid IndoBERT + XGBoost berhasil mencapai akurasi evaluasi sebesar 90,60% dalam mengklasifikasikan popularitas konten.
