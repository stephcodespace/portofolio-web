Hall of Memories — Sistem Pemesanan Tiket Museum

Website pemesanan tiket museum di Bogor yang dikembangkan untuk memberikan pengalaman kunjungan museum yang lebih mudah dan praktis. Website memungkinkan pengguna menemukan informasi museum, merencanakan kunjungan, memilih waktu dan jumlah tiket, hingga melihat detail transaksi secara online.

UMLERDUI PrototypeUse Case

Halaman Beranda Pemesanan

Fungsi Website

Sistem ini dirancang untuk mempermudah calon pengunjung memesan tiket museum secara daring — mulai dari memilih jenis tiket, mengisi data kunjungan, hingga mendapatkan konfirmasi pemesanan — tanpa perlu mengantre di lokasi.

Fitur-fitur yang Dirancang

  • Museum Discovery — Menampilkan daftar museum beserta informasi, jam operasional, harga tiket, dan koleksi gambar.
  • Online Ticket Booking — Pengguna dapat memilih museum, menentukan waktu kunjungan, jumlah tiket, dan melihat total harga.
  • User Authentication — Fitur registrasi dan login untuk mengakses layanan pemesanan.
  • Transaction Details — Menampilkan detail transaksi setelah proses pemesanan.

Cakupan Pengerjaan

Cakupan pengerjaan meliputi analisis kebutuhan web, perancangan antarmuka, implementasi pemesanan tiket, integrasi database MySQL, pengembangan Web User dan Web Admin, serta pengujian fungsional sistem.**
